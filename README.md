ProjectDiscovery builds the open-source security toolchain trusted across offensive security and attack-surface management -- Nuclei, Subfinder, httpx, Katana, Naabu, dnsx and more -- and the ProjectDiscovery Cloud Platform (PDCP) that operationalizes them for continuous exposure management. Its REST API at api.projectdiscovery.io exposes asset discovery and enumeration, template-driven vulnerability scanning, credential-leak monitoring, scan scheduling, configuration, and template management, authenticated with a single X-API-Key header over HTTPS. Founded by the creators of Nuclei and backed by Accel, ProjectDiscovery serves security teams automating attack-surface discovery and vulnerability detection at scale.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ProjectDiscovery: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
